# Submission Guide

## What to include
For the lab submission, you should package:
- `Quick.java`
- `answers.txt`
- `output.txt`

## PowerShell commands
Run these from the lab folder:

```powershell
Set-Location 'c:\Users\Administrator\Desktop\DSA Coursework\lab-1'
Compress-Archive -Path Quick.java, answers.txt, output.txt -DestinationPath submission0.zip -Force
```

If you are making a resubmission, change the zip name to `submission1.zip`, `submission2.zip`, and so on.
